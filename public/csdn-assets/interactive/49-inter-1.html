shuffle 对比：同类聚集 vs 均衡打乱

训练集为什么必须 shuffle？看一批按类别排序的数据，被打乱前后，每个 batch 里样本的构成差异。

原文建议：做一个"shuffle 对比"动画，左 shuffle=False 同类聚集弹警告，右 shuffle=True 均衡弹绿勾。
原始数据（按类别排序：红=猫 / 蓝=狗 / 绿=鸟 / 黄=车 / 紫=花，每类 8 条，共 40 条）

shuffle = False（不打乱）

按原顺序每 4 条一组取 batch
⚠ 同类聚集，梯度偏颇，模型学崩

shuffle = True（打乱）

随机重排后每 4 条一组取 batch
✓ 分布均衡，训练稳定
