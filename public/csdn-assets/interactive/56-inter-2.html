设备搬运 Demo：模型 / 输入 x / 标签 y 必须同设备

核心需求：点击按钮把模型、输入 x、标签 y 在 CPU / GPU 之间搬动；三者设备不全一致时实时弹出红色报错 Expected all tensors to be on the same device；一旦三者都落到 GPU，报错变绿勾“计算成功”。

🏬 CPU 仓库

容量大、搬运慢（DataLoader 默认产出地）

🏭 GPU 车间

算力猛、工位有限（模型与数据要搬来这）

✕ RuntimeError
Expected all tensors to be on the same device

提示：把三个方块都搬进 GPU 车间即可消除报错（DataLoader 产出的 x、y 默认在 CPU，需手动 .to(device)）。
